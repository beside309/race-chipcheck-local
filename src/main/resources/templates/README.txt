Excel模板格式说明：

列名（第一行）：
参赛号码 | 姓名 | 芯片1 | 芯片2 | 芯片3 | 芯片4

示例数据：
001      | 张三 | C24BB805AA003989 |              |              |
002      | 李四 | C24BB805AA003990 | C24BB805AA003991 |              |
003      | 王五 | C24BB805AA003992 |              |              |

注意事项：
1. 参赛号码和芯片1为必填项
2. 芯片2、芯片3、芯片4为可选项
3. 不能有重复的参赛号码
4. 不能有重复的芯片号
